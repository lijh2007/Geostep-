# 0.4.5：后台引导、诊断导出与邮箱反馈

主应用 0.4.5/code9；LSPosed 模块 0.3.13，内置 Root 0.1.1。相对内部版 0.4.4，本轮仅增加引导与诊断功能；相对正式版 0.4.3，本次发行也包含模块/载荷更新。升级和定位验证范围见 [更新日志](../CHANGELOG.md)。

## 功能

- “运行状态 → 运行环境”固定显示后台持续运行引导。它是设置说明，不会根据标准电池白名单误报厂商策略已就绪。小米优先打开本应用省电页，失败时回退系统应用详情；其它品牌使用应用详情，并提示电池/耗电管理路径。
- “偏好设置 → 诊断与反馈”提供保存诊断日志和邮件反馈（附日志）。原运行状态页的导出使用相同报告生成器。
- “关于 Geostep”显示版本与邮箱 `1590887927@qq.com`（0.8.2 起；此前为上游邮箱），提供邮件联系和复制按钮。
- 使用系统文件创建器保存 `.txt`，不申请额外存储权限。邮件分享限制到可处理 mailto 且支持附件分享的应用；缺少邮件应用时提示先保存文件再发送。

## 报告与附件边界

报告包含生成时间、设备型号/Android/API/系统构建/ABI、主包及安装/加载模块版本、引擎状态、回执年龄、钩子状态、心跳过期计数和最近最多 500 条带时间戳的进程内事件。没有日志时如实提示；应用进程重启后旧内存日志不再可用。

不序列化 EngineState 中的 SimConfig，不导出收藏、历史、路线文件或完整设置。报告过滤已知地图 Key，以及错误文本中常见的凭据字段、链接和坐标字段。用户仍可先保存查看再分享。

FileProvider 不对外导出，唯一根目录为应用缓存下 `diagnostics/`；分享的是 `content://` URI，并仅附带临时读取授权。缓存最多保留 8 个报告。点击邮件反馈仅生成草稿，不自动发送。

- 6 项设备检查通过：实际报告生成并过滤本机自定义 Key；非导出 FileProvider；通过 ContentResolver 写入/读回报告；禁止将其它应用私有文件路径映射为附件；邮件地址、文本附件 URI、ClipData、只读权限；联系 intent 和设置回退 intent。厂商省电入口在本机可解析。未启动或发送测试邮件。
